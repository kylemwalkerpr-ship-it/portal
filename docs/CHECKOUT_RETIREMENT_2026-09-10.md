# Checkout retirement — 2026-09-10

`checkout.yousafeconsultancy.com` is retired and must not be restored as an active YouSafe surface.

Current public commerce/discovery destinations:

- Services marketplace: `https://market.yousafeconsultancy.com/`
- Provider directory: `https://market.yousafeconsultancy.com/providers`
- File Shop: `https://market.yousafeconsultancy.com/shop`
- File Shop product: `https://market.yousafeconsultancy.com/shop/<product-slug>`
- Authenticated workspace: `https://portal.yousafeconsultancy.com/`

Historical Marketplace `/templates` URLs are compatibility aliases only. They permanently redirect to the canonical File Shop equivalents and must not be used for new internal links, canonicals, structured data, or sitemap entries.

Older briefs, audit snapshots, and strategy documents that mention the retired checkout host or `/templates` as canonical routes are historical records. This file and `docs/MARKETPLACE_SEO_URL_CONTRACT.md` are authoritative for current routing.
