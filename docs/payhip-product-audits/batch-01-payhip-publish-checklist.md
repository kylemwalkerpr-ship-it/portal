# Batch 01 Payhip Publish Checklist

This is a fail-closed release checklist for the first nine Payhip products. A product is not complete merely because the Marketplace/Apex code is ready.

For each product:

- [ ] Buyer-facing file(s) generated from the maintained manifest.
- [ ] File opens after generation and contains usable fillable fields.
- [ ] Official-source guidance page is present.
- [ ] Payhip attachment replaced with the audited buyer-facing file(s).
- [ ] Exact file count and format in listing copy match the attachment(s).
- [ ] Researched Batch 1 price applied.
- [ ] Batch 1 tags applied.
- [ ] Selected real Pexels photograph used for cover; no AI-generated cover and no fake visa/government document artwork.
- [ ] Cover title matches the product exactly and includes a discreet preparation-resource trust line.
- [ ] Payhip blog post published from `lib/payhipBatch1Commercial.ts` copy.
- [ ] Payhip blog links to the matching Apex product-led guide.
- [ ] Payhip product links to the matching Apex product-led guide where Payhip permits it.
- [ ] Apex article links to the exact Payhip product and Marketplace detail page.
- [ ] Cross-sells are relevant to the buyer's situation and do not imply a legal requirement.
- [ ] Official-source links were checked again immediately before publication.
- [ ] Live Payhip product opened in an authenticated browser after save and compared against the manifest.
- [ ] Test purchase/download path verified or an equivalent owner-library download proves the customer receives the same audited file(s).
