## 0) Operating rules

| Rule | YouSafe translation |
|------|---------------------|
| Load context once | Pin a **Studio Business Context** block (below) into Configure notes / Master Engine knowledge — not a chat paste every time |
| Quick wins first | Prefer GSC position 4–15 + high-imp/low-CTR owners before net-new URLs |
| Spreadsheet-shaped competitor compares | Competitor Radar signals + competitiveGap lane — durable rows, not essay spam |
| Don’t guess | Fail-open; say “unknown”; never fake GSC/Ahrefs numbers |
| One intent → one owner | Existing ownership registry / resolveOwner — no sibling cannibal pages |
| Execution order | 6-week cadence below; specialists stay dull and POST intel signals |

## 3) Playbook sprints (6 weeks)

### Week 1 — Context + competitor patterns (Discover / Research)
1. Refresh §1 Business Context for each active region.
2. Pull open **Competitor Radar** + **Policy Desk** signals from Specialist Intel; queue high-urgency into Discover.
3. For each cash-cow intent, run competitive pattern pass (table):
   - competitor | new URL/title | intent overlap | update-on-owner vs ignore | source
4. **Done when:** ≤5 queued opportunities with owner URL or “needs owner” flagged; no new siblings without ownership check.

### Week 2 — Page-2 / CTR goldmine (Discover → Draft)
1. From GSC (Studio Discover / GSC Sync): list queries with position **4–15** or **11–20**, impressions ≥ threshold, cash-cow intent.
2. High impressions + low CTR → title/meta rewrite jobs on **existing owners** only.
3. Ship through Draft → Review (Harper + AI Style) → Approve.
4. **Done when:** top 10 goldmine rows have either a merged fix or an explicit defer reason.

### Week 3 — On-page owner completeness (Draft / Review)
For each priority owner:
- Title / H1 / first 100 words carry primary intent (natural, YMYL-safe)
- Depth vs SERP (competitiveGap / Master Engine)
- FAQ + citations to official sources
- Internal links from related owners (estate interlink tools)
- **Done when:** shipReady / audit gates green; no leaked markdown; no cannibal clusters opened

### Week 4 — Intent × region coverage (Research → Approve)
1. From ownership registry: which cash-cow intents lack a regional owner (usa/uk/ca/au)?
2. Build **only missing owners** — never city-farm pages.
3. Brief in Studio (Grok pin) → Draft → Approve → live verify.
4. **Done when:** coverage matrix updated; orphans / duplicate titles = 0 for the batch

### Week 5 — Demand + support gaps (Discover)
1. **Support Triage** patterns → FAQ / clarifying sections on owners (or new FAQ owner if truly new intent).
2. **Lead Desk** ICP tags → soft CTA / marketplace path only where `supply_first` allows.
3. **Marketplace Scout** gaps → Shop SEO; do not rank empty market categories.
4. **Done when:** each gap is a Studio job or a dismissed signal with reason

### Week 6 — Authority + Track
1. On Approve, Authority Multiplexer signal auto-enqueues — produce repurpose pack (X / thread / video hooks / newsletter) **for approval only**.
2. Overnight Ops priorities → next week’s three ranking moves.
3. Rescore path-to-100 / Master Engine on touched owners.
4. **Done when:** Track shows deploy green; no broken sitemaps; no orphaned ships

## 4) Prompt pack (YouSafe-native — paste into Studio / OpenCode briefs)

### P0 — Context lock
Use §1. Add: “Reference this for every audit and brief. Never re-ask. Prefer update-on-owner. YMYL honesty.”

### P1 — Competitor pattern table (was: GBP categories)
```
Using Competitor Radar deltas + these competitor URLs […], build a table for region [US|UK|CA|AU]
and cash-cow intents […]: competitor, URL, title angle, overlap with our owner [url or none],
recommended action (update-owner | ignore | new-owner-only-if-gap), impact high/med/low.
No invented metrics. Cite sources.
```

### P2 — Attribute → on-page trust checklist (was: GBP attributes)
```
Compare our owner [url] vs competitors [urls] for trust/SERP-feature parity:
E-E-A-T signals, FAQ, tables, official citations, CTA clarity, freshness.
Table: signal | we have | they have | action on our owner. No Map Pack attributes.
```

### P3 — Review/support language mining (was: review teardown)
```
From Support Triage patterns + public competitor FAQ/blog themes (cited),
list top phrases customers use for [intent]. Propose FAQ questions for owner [url].
Do not fabricate reviews or star ratings.
```

### P4 — Response / FAQ templates (was: review responses)
```
Draft 3 YMYL-safe FAQ answers for owner [url] that clarify process without guarantees
or legal advice. 40–80 words each. Cite official source links to add in Research.
```

### P5 — Distribution calendar (was: GBP posts) → Authority Multiplexer
```
After Approve of [canonical], draft repurpose pack: 5 X posts, 6–8 beat thread,
3 video hooks, 4-para newsletter tease. Soft CTA to owner or market gig only if supply exists.
Mark lead hook. Never schedule external sends.
```

### P6 — Owner services / scope block (was: GBP services)
```
Audit owner [url] vs site nav/marketplace categories. List missing scope bullets
that belong on this owner (not new URLs). Write 40–60 word scope blurbs, YMYL-safe.
```

### P7 — Title / meta / intro variants (was: GBP description)
```
Write 3 title (<60) + meta (<155) + 100-word intro variants for owner [url]:
(A) ranking clarity (B) CTR/conversion (C) trust/E-E-A-T.
Include primary keyword naturally; no stuffing; no outcome promises.
```

### P8 — Visual / evidence plan (was: photo audit)
```
For owner [url], list evidence assets to add (official diagrams, process steps,
citation screenshots we have rights to — not stock). Skip geotag photo velocity.
```

### P9 — Keyword gap (GSC/Ahrefs first)
```
From Studio GSC + Ahrefs issues for [host], list keywords competitors rank 1–20
where we have no owner or a weak owner. Filter cash-cow intents only.
Columns: keyword, volume/difficulty if known else unknown, competitor positions,
action Optimize existing | Create owner | Defer. No guesses dressed as data.
```

### P10 — Money-page / cannibal pass
```
For hosts […], find pages ranking for the wrong intent or competing with the true owner.
Output: query | current URL | correct owner | action (consolidate | retarget | 301 proposal).
```

### P11 — Intent × region page brief
```
Missing owner: [intent] × [region]. Produce Studio brief: slug, title, H1, outline H2s,
official sources, internal links to existing owners, CTA to market only if supply_first OK.
Refuse city-farm variants.
```

### P12 — GSC 30-day sprint
```
From last 90d GSC: page-2 + low-CTR lists. Build 30-day sprint:
Week1 titles/H1s, Week2 thin-content expands, Week3 interlinks, Week4 metas.
For each item write the exact copy to paste — not instructions.
```
