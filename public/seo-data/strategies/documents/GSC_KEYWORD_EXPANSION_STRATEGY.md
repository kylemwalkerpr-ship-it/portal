### Fix Strategy for Housing Guide Titles

The dynamic guide titles are generated by `compactGuideTitle()` in `app/guide/[slug]/page.tsx`. To fix the housing guide titles that show in SERPs, modify `compactGuideTitle()` to produce city-specific titles for housing:

```
Current: "{University Name} Housing"
Target:  "{University Name} Housing: {City}, {State} Off-Campus Guide"
```

The city/state data already exists in the university data objects in `lib/expanded-articles/content.ts`.

### Fix Strategy for International Student Guide Titles

```
Current: "{University Name} F-1 Guide"  
Target:  "{University Name} F-1 Guide 2026 — International Student {City}"
```

## 8 · Content.ts Title Override Brief

The following `compactGuideTitle()` overrides or base title changes are needed in `lib/expanded-articles/content.ts` to fix SERP titles for high-impression guide pages:

### Change A: Modify `compactGuideTitle()` to include city for housing guides

Add to the function:
```typescript
// Add city/state info for housing guides that rank
.replace(/^(.+): Student Housing Guide$/, (_, uni) => {
  const u = UNIVERSITIES.find(u => u.name === uni)
  return u ? `${uni} Student Housing ${u.city} ${u.state} Guide` : `${uni} Housing`
})
```

### Change B: Add specific overrides for high-CTR-potential guides

Add before the return statement:
```typescript
// Specific title overrides for guides ranking in SERPs
const SERP_TITLE_OVERRIDES: Record<string, string> = {
  'american-university-student-housing': 'American University Student Housing DC — Off-Campus & Dorm Guide',
  'uk-king-s-college-london-international-student-guide': 'King\'s College London International Student Guide 2026',
  'creighton-university-student-housing': 'Creighton University Student Housing Omaha — Off-Campus Apartments',
  'marquette-university-student-housing': 'Marquette University Student Housing Milwaukee — Off-Campus Guide',
  'kansas-state-university-student-housing': 'Kansas State University Housing Manhattan KS — Off-Campus & On-Campus',
  'chapman-university-international-student-guide': 'Chapman University F-1 Guide Orange CA — International Student Guide',
}
if (slug in SERP_TITLE_OVERRIDES) return SERP_TITLE_OVERRIDES[slug]
```
